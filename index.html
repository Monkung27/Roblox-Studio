คู่มือการใส่สคริปต์ใน Roblox Studio สำหรับมือใหม่

ทำความเข้าใจโฟลเดอร์และประเภทของสคริปต์อย่างถูกต้อง

1. ความแตกต่างของประเภทสคริปต์ (Script Types)

📜 Script (Server Script)

ทำงานที่ เซิร์ฟเวอร์ (Server) ทุกคนในเกมจะมองเห็นผลลัพธ์เหมือนกัน ใช้สำหรับแจก EXP, บันทึก DataStore, สปอว์นมอนสเตอร์ และคำนวณดาเมจ

ใส่ใน: ServerScriptService, Workspace
📜 LocalScript (Client Script)

ทำงานที่ เครื่องผู้เล่นแต่ละคน (Client) คนอื่นจะไม่เห็น ใช้สำหรับตรวจจับการกดปุ่มคีย์บอร์ด, อนิเมชันตัวละคร, และหน้าจอ UI

ใส่ใน: StarterPlayerScripts, StarterGui, Tools
📜 ModuleScript

สคริปต์ที่เก็บฟังก์ชันหรือตารางข้อมูลส่วนกลาง เพื่อให้สคริปต์อื่นๆ เรียกใช้งานซ้ำได้ (ผ่าน require())

ใส่ใน: ReplicatedStorage

2. หน้าที่ของแต่ละโฟลเดอร์หลักใน Explorer

โฟลเดอร์ (Service) คำอธิบายและหน้าที่
📁 ServerScriptService ที่เก็บโค้ดสำคัญของเกมที่ปลอดภัยที่สุด ผู้เล่น (Client) มองไม่เห็นโค้ดในนี้ ใช้เก็บระบบเลเวล, ระบบเซฟ, ระบบคำนวณเงิน
📁 ServerStorage ที่เก็บสิ่งของ โมเดลมอนสเตอร์ หรือไอเทมที่ยังไม่ต้องการให้ปรากฏในเกมตอนแรก เพื่อนำมา Clone ในภายหลัง
📁 ReplicatedStorage พื้นที่ส่วนกลางที่ทั้ง Server และ Client เข้าถึงได้ ใช้สำหรับวาง RemoteEvent, RemoteFunction เพื่อส่งข้อมูลหากัน
📁 StarterPack อาวุธหรืออุปกรณ์ (Tool) ที่จะใส่เข้าไปในกระเป๋าของผู้เล่นอัตโนมัติทันทีที่เข้าเกมหรือเกิดใหม่
📁 Workspace โลก 3 มิติในเกม ทั้งหมดที่ตาผู้เล่นมองเห็น เช่น แผนที่, กำแพงกั้นโซน, จุดสปอว์น, และตัวละคร NPC

3. ข้อควรระวังสำคัญก่อนเปิดเซิร์ฟเวอร์จริง

  • ⚠️ ต้องเปิดสิทธิ์ DataStore: ไปที่ Home > Game Settings > Security > Enable Studio Access to API Services ติ๊กเปิดทุกครั้ง มิฉะนั้นระบบเซฟจะไม่ทำงานใน Studio
  • ⚠️ อย่าทำดาเมจฝั่ง Client: อย่าสั่งลดเลือดมอนสเตอร์ใน LocalScript เพราะผู้เล่นสายแฮ็กจะสามารถเสกดาเมจได้ไม่จำกัด ให้ส่ง RemoteEvent ไปให้ Server เช็กเสมอ
  • ⚠️ ชิ้นส่วน Handle ของดาบ: ใน Tool ของดาบ Part ต้องตั้งชื่อว่า Handle (ตัว H พิมพ์ใหญ่) เท่านั้น ตัวละครถึงจะหยิบขึ้นมาถือได้
